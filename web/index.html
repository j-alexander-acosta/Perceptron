El fenómeno del cilindro (Diapositivas 37–40):
• Adentro del polígono de N lados, el punto cumple las N desigualdades: Σ yi = N.
• Afuera (a distancia d > r), el punto queda del lado «bueno» de aproximadamente la mitad de las rectas. En el límite N → ∞:
Σi=1..N yi = N · [ 1/2 + (1/π) · arcsin(r / d) ] → N / 2
• ¿Por qué restar el sesgo -N/2? Porque si queremos unir varios círculos en una sola capa oculta para rellenar cualquier región (Diap. 41), los pisos de altura N/2 se sumarían falsamente afuera. Con el sesgo -N/2, el exterior vale ≈ 0.

Diapositivas 49, 52–54
Tres verbos que NO dicen lo mismo (Diapositiva 52):
1. Representar (modelar exactamente): La red calcula f y nada más que f. Con unidades de umbral eso solo ocurre si f ya es escalonada.
2. Aproximar: Fijado cualquier error ε > 0, existe una red finita cuyo error es menor que ε.
3. El límite: Al hacer los pulsos más angostos, ε → 0, pero para cualquier cantidad finita de neuronas la suma sigue siendo escalonada.
Ojo con la capa de salida (Diapositiva 54): Si la neurona de salida tiene una activación (ej. sigmoide), el MLP es un aproximador universal hacia el rango de esa activación, como (0, 1).

📐 Riesgo Empírico, Absorción del Umbral e Historial de Actualizaciones
Unidad II • Diapositivas 5–22
¿Qué significa aprender una red? (Diaps. 5–13):
• Como la función real g(X) es desconocida, no podemos calcular TotalErr(W) = ∫ error(f(X; W), g(X)) dX.
• En su lugar minimizamos el Riesgo Empírico sobre N muestras (Xi, di):
TrainLoss(W) = (1 / N) · Σi=1..N error( f(Xi; W), di )
• Truco para absorber el umbral T (Diap. 16): Añadimos una entrada constante xN+1 = 1 con peso wN+1 = -T. Así Σ wixi ≥ T ⇔ w · x ≥ 0 (hiperplano que pasa por el origen).

Haz clic en cualquier fila para inspeccionar geométricamente esa actualización w ← w + yixi:

PasoMuestra xiyiw antesw después (w + yixi)
Teorema de Convergencia (Diap. 20): Si los datos son linealmente separables con margen γ > 0 y radio R = max ‖xi‖, el perceptrón converge en a lo más (R / γ)2 actualizaciones. Si NO son separables (Diap. 21), entra en un ciclo infinito.

¿Por qué el conteo de errores no sirve para optimizar redes? (Diaps. 31–34):
Al mover ligeramente T sin cruzar ninguna muestra (por ejemplo entre T = 0.45 y T = 1.05), el número de errores permanece constante en 2: la derivada es exactamente 0. Con una activación sigmoide σ(z) = 1 / (1 + e-z), cada muestra aporta una distancia continua y la pendiente indica en todo momento hacia dónde mover T.
🧩 ¿Por qué no escala a Multicapa? + ADALINE (Regla Delta / LMS)
Unidad II • Diapositivas 23–29
El problema del doble pentágono (Diaps. 23–27):
Incluso si conociéramos los pesos exactos de todas las neuronas de un MLP salvo una sola neurona de primera capa, los puntos positivos globales (adentro de cualquiera de los dos pentágonos) NO son linealmente separables para esa recta individual. Entrenar unidades de umbral en cascada exige adivinar las etiquetas booleanas intermedias de cada capa oculta: un problema combinatorio exponencial.
Tasa de aprendizaje ADALINE (η): η = 0.025
MSE Época 1 0.2310
MSE Época 30 0.1112
Pesos ADALINE Aprendidos [0.48, 0.17]
Paréntesis Histórico — ADALINE (Widrow y Hoff, 1960, Diap. 28):
La Regla Delta o LMS mueve la actualización antes del escalón, minimizando ½(d - z)2 directamente sobre la pre-activación lineal z = w · x:
wi ← wi + η · (d - z) · xi
Aun así, encadenar transformaciones puramente lineales colapsa a una sola capa lineal, y mantener el umbral frena el paso del gradiente entre capas (MADALINE, Diap. 29).

¿Por qué preferimos Entropía Cruzada sobre L2 en clasificación? (Diaps. 47–48):
Cuando la neurona está muy equivocada (ej. d = 1 pero Y = σ(z) ≈ 0.05), la sigmoide está en su zona plana (σ'(z) ≈ 0). Con L2, el gradiente respecto a z es (Y - d)·σ'(z) ≈ 0 (aprendizaje lentísimo). Con Entropía Cruzada, la derivada -1/Y cancela exactamente la saturación de la sigmoide dejando ∂div / ∂z = Y - d.

Dos Propiedades Geométricas Clave (Diaps. 12–15):
∇xf = [ ∂f/∂x1, …, ∂f/∂xd ]⊤   ⇒   Δy ≈ ∇xf · Δx = |∇f| |Δx| cos(θ)
• Propiedad 1 (Diap. 14): Con largo de paso fijo |Δx|, Δy es máximo en θ = 0° (alineado con +∇f) y mínimo (baja más rápido) en θ = 180° (en contra: -∇f).
• Propiedad 2 (Diap. 15): Moverse a lo largo de una curva de nivel no cambia f (Δy = 0 ⇒ cos(θ) = 0), por lo que el gradiente es siempre perpendicular a las curvas de nivel.

La derivada como multiplicador local y los «impostores» (Diaps. 8–10):
A resolución suficientemente fina, toda función suave es localmente lineal: Δy ≈ f'(x)Δx. En los mínimos y máximos la curva es localmente plana (f'(x) = 0), pero ojo con los puntos de inflexión con derivada nula: también tienen f'(x) = 0 sin ser ni mínimos ni máximos.

Condición de mínimo en una variable (Diaps. 19–21):
Resolver f'(x) = 0 encuentra los puntos críticos (puntos de giro), pero no distingue entre subir y bajar. La segunda derivada f''(x) los delata:
• f'(x) = 0 y f''(x) > 0 ⇒ Mínimo local (en x2 - 4x + 5: 2x - 4 = 0 ⇒ x = 2, f''(2) = 2 > 0, mínimo global con f(2) = 1).
• f'(x) = 0 y f''(x) < 0 ⇒ Máximo local.
• f'(x) = 0 y f''(x) = 0 ⇒ Puede ser punto de inflexión.
🧮 El Hessiano ∇²f en Varias Variables y Ejemplo 3×3 Resuelto
Unidad III • Diapositivas 22–25
Geometría de ∇²f:
Ejemplo Resuelto de las Diapositivas 24–25:
Minimizar f(x₁, x₂, x₃) = x₁² + x₁(1 - x₂) + x₂² - x₂x₃ + x₃² + x₃
∇xf = [ 2x₁ + 1 - x₂,  -x₁ + 2x₂ - x₃,  -x₂ + 2x₃ + 1 ]⊤ = [0, 0, 0]⊤  ⇒  x* = (-1, -1, -1)
Evaluando el Hessiano 3×3 (simétrico y constante en todo punto):
∇2xf = [ [2, -1, 0], [-1, 2, -1], [0, -1, 2] ]  ⇒  λ1 = 3.414,  λ2 = 0.586,  λ3 = 2.0
Como todos los valores propios son positivos (λi > 0), el Hessiano es definido positivo (cuenco en toda dirección) y x* = (-1, -1, -1) es un mínimo con f(-1,-1,-1) = -1.

🏃 Soluciones Iterativas: Guiado por Signo vs. Magnitud del Gradiente
Unidad III • Diapositivas 26–33
¿Por qué usar la magnitud de la derivada y no solo su signo? (Diaps. 29–31):
• Algoritmo trivial guiado por el signo (Diap. 29): x(k+1) = x(k) - sign(f'(x(k))) · paso. Desperdicia la magnitud: da pasos del mismo tamaño lejos y cerca del mínimo, oscilando sin frenar.
• Descenso por gradiente (Diaps. 30–31):
x(k+1) = x(k) - η(k) ∇xf(x(k))
El paso efectivo es η · |f'|: avanza rápido en zonas empinadas y frena solo al acercarse a un punto crítico donde ∇f → 0.
¿Cuándo parar? Criterios prácticos de convergencia (Diaps. 32–33):
En aritmética de punto flotante los ceros exactos no existen; se detiene la iteración cuando:
1. La función deja de bajar: |f(x(k+1)) - f(x(k))| < ϵ1
2. El gradiente es casi nulo: ‖∇xf(x(k))‖ < ϵ2
